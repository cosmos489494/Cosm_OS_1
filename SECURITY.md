# Política de Segurança

Se você encontrar uma vulnerabilidade de segurança, por favor, relate-a
na seção Discussões deste repositório.

Ao criar uma discussão, forneça o máximo de informações possível,
incluindo:

- Descrição da vulnerabilidade;
- Build afetada;
- Passos para reproduzir o problema;
- Impacto potencial;
- Qualquer evidência ou exemplo relevante.

A equipe analisará o relato e responderá assim que possível.
