Build 1.3.2026 — foi a build em que o Cosm OS 1 ganhou visão: nasceu o driver de vídeo, criado com uma divisão de trabalho bem definida que vale até hoje — o driver só consulta e reporta (lê a placa via PCI, acha o framebuffer, sonda as resoluções disponíveis e restaura o modo original ao terminar, sem deixar a máquina bagunçada), e devolve um bloco de especificações; quem decide e aplica é o kernel, seguindo a política aprovada de sempre escolher a resolução mais alta que o console aceitar.
