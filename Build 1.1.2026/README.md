Build 1.1.2026 — foi a build em que o Cosm OS 1 passou a realmente ligar: o bootloader foi montado como aplicação UEFI (.efi) e empacotado dentro de uma partição ESP em formato FAT, gerada automaticamente em cada build — a única exceção aprovada da regra "arquivos separados na raiz", porque é o próprio firmware que exige essa estrutura (EFI/Boot/bootx64.efi) para aceitar qualquer mídia. O script de build passou a produzir uma ISO híbrida com essa partição embutida, o computador passou a reconhecer o disco como legítimo e o nosso código em Assembly recebeu o primeiro controle vindo de um firmware real
