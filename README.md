# Cosm OS 1

O **Cosm OS 1** é um sistema operacional independente para computadores **x86-64**, desenvolvido inteiramente em **Assembly** e iniciado diretamente por **UEFI**.

O objetivo do projeto é construir um sistema operacional do zero, sem depender de outro sistema para inicializar e sem utilizar endereços fixos. Dessa forma, o Cosm OS 1 busca oferecer controle direto sobre o hardware e explorar, na prática, o funcionamento de um computador desde o processo de boot.

## Objetivo

- Criar um sistema operacional próprio para a arquitetura x86-64;
- Inicializar diretamente através de UEFI;
- Desenvolver todos os componentes essenciais em Assembly;
- Evitar dependências de outros sistemas operacionais;
- Trabalhar sem endereços fixos;
- Executar o sistema em uma máquina real.

## Status

O Cosm OS 1 está em desenvolvimento contínuo e já consegue inicializar em hardware real.
